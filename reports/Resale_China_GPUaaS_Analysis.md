# 跨区域算力溢出与灾备策略

> 本附录探讨利用中国等低成本地区 GPU 算力的可行性。按审阅意见，不命名为"转售战略"，而是作为溢出和灾备场景评估。

---

## 评估维度

| 维度 | 说明 |
|------|------|
| 等效 GPU 和精度 | H100 vs A100 性能不等价；需 SPEC benchmark 对比 |
| 数据分类 | 哪些工作负载可跨境，哪些必须本地 |
| 网络延迟 | 需实测 Manila → 中国目标区域 p50/p95 |
| 数据合规 | 菲律宾 DPA / NPC 对跨境传输的要求 — 需法律顾问意见 |
| 出口管制 | 美国 EAR 对 H100 出口中国的限制；中国 H100 价格更高 |
| SLA 与赔偿 | 散户平台无企业 SLA，不适合企业客户 |
| 全量成本 | 含专线、公网流量、双地冗余、失败重试、汇率风险 |

## 初步发现

- 中国西部电价确实更低（~$0.06/kWh vs 菲律宾 PPA $0.085/kWh），但电费在 GPUaaS TCO 中占比 <15%
- 中国 H100 因出口管制反而更贵（$11-17/hr 来源不明，需验证）
- 中国散户平台（如 AutoDL）A100 价格极低（~$0.7/hr），但无 SLA、无合规、无企业级支持
- **数据主权是 PLDT 核心卖点**，跨境算力直接削弱这一优势

## 建议定位

- **仅用于**：非敏感数据的批量训练/推理溢出、开发测试环境、灾备冗余
- **不适用于**：政府/金融/医疗客户、需要数据驻留的企业客户、实时交互式服务
- 跨境数据合规应由菲律宾当地法律顾问给出正式意见，不应在商业报告中替代法律分析
