# 转售中国 GPUaaS 可行性分析

## 1. 电价对比
- 中国西部(内蒙/四川): $0.06/kWh (全球最低档)
- 菲律宾 PPA: $0.085/kWh (+42%)
- 菲律宾商业: $0.161/kWh (+168%)
- 中国电价确实更便宜, 但 PLDT 走 PPA 差距不大

## 2. 中国 GPUaaS 源头价格
- 大厂(阿里/腾讯) A100: ~$4.85/hr (并不比国际便宜!)
- 散户(AutoDL) A100: ~$0.7/hr (极便宜, 但无 SLA)
- H100 在中国: $11-17/hr (比国际更贵, 出口管制)

## 3. 转售毛利率
- 转售 AutoDL A100: 成本$0.7 → 卖$2.69 → 毛利67% ✅
- 转售阿里云 A100: 成本$4.85 → 卖$4.85 → 毛利0% ❌
- 转售 AutoDL H100: 成本$2.5 → 卖$3.20 → 毛利22% ⚠️

## 4. 五大致命问题
1. 数据主权: 跨境数据 → 核心卖点归零
2. 延迟: 200ms+ vs 本地5ms
3. 无 SLA: 散户平台做不了企业级
4. H100 出口管制: 中国更贵
5. 合规风险: NPC监管 + 南海光缆

## 5. 最优策略: 混合架构
- 70% 本地自建 VITRO (企业客户)
- 30% 海外转售 (训练/溢出/开发者)
- CapEx 降低30%, 毛利率提升到50%
